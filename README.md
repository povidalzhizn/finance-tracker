# Финансы

Личный учёт для iPhone: PWA, работает без сети и без AI. Загружаешь выписки Т-Банка и Сбера, приложение само разносит траты по правилам и спрашивает только то, что не может решить. Данные живут в Google Таблице «Учет_доходов_и_расходов (2)»: лист «Операции» и аналитика остаются как были.

В репозитории нет данных, правил и токенов: имена и суммы хранятся только в таблице и на телефоне. Файлы выписок никуда не отправляются, они читаются прямо на телефоне.

## Как разносятся операции

1. **Отсев.** Ошибки банка, строки с «Учёт в аналитике: Нет», свои переводы.
2. **Сверка с таблицей.** Та же дата и сумма (±1 ₽, до 5 ₽ при той же категории или комментарии) считается уже внесённой, новой строки не будет. Пустой «Счёт» у ручной записи дописывается, сумма не меняется.
3. **Правила.** Лист «Правила импорта»: подстрока в описании или категории банка, банк, условие. Срабатывает самое точное правило, такая операция вносится сразу и попадает в отчёт импорта.
4. **Догадка.** Категория банка или MCC. Приходит карточкой с готовым вариантом, «Верно» — одно нажатие.
5. **Вопрос.** Всё остальное: переводы людям, наличные, кредитка, возвраты, неизвестные магазины.

Ответ с галочкой «Всегда так» дописывает строку в «Правила импорта» и сразу разбирает остальные карточки с тем же магазином. Так приложение учится, отдельной памяти нет.

Что приложение понимает в колонке «Условие»: `сумма до N`, `сумма от N`, `исходящий`, `входящий`, `будни ~13:00` (будни с 12:00 до 15:00 → «Кафе и рестораны», «Обед»). В колонке «Описание»: варианты через ` / `, текст в скобках игнорируется, `мелкие суммы` значит меньше 1000 ₽. Категория `по назначению` и тип `спрашивать` дают вопрос, текст условия показывается подсказкой. Остальной текст условий приложение не читает.

## Устройство

- `app/engine.js` — разбор выписок и разноска, чистая логика.
- `app/store.js` — снимок таблицы и очередь записей на телефоне (IndexedDB), обмен со скриптом, чтение файлов.
- `app/index.html` — интерфейс. `app/sw.js` — офлайн. `app/vendor/` — pdf.js для чтения выписок Сбера.
- `gas/Code.gs` — Apps Script внутри таблицы. Лист `_импорт` создаётся сам: журнал обработанного, чтобы ничего не внеслось дважды.
- `tools/dev-server.mjs` — стенд: приложение и настоящий `Code.gs` на поддельных сервисах Google с выдуманными данными, адрес скрипта `http://localhost:5198/exec`, токен `dev-token`.
- `test/` — проверки движка и скрипта: `node --test "test/*.test.mjs"`.

## Развернуть скрипт (один раз)

1. Открыть таблицу → Расширения → Apps Script.
2. Если там уже есть код, не затирать его: добавить новый файл. Вставить содержимое `gas/Code.gs`, сохранить.
3. Выбрать функцию `setup` → Выполнить → разрешить доступ. Токен появится в журнале выполнения. Скрипт создаст лист `_импорт` и запомнит последнюю дату по каждому счёту: операции старше неё приложение пропускает.
4. Начать развёртывание → Новое развёртывание → тип «Веб-приложение». Запуск от имени: «Я». Доступ: «Все». Скопировать ссылку, заканчивается на `/exec`.

После правок `Code.gs`: Начать развёртывание → Управление → карандаш → Новая версия. Ссылка останется той же.

## Подключить телефон

Сайт: https://povidalzhizn.github.io/finance-tracker/. Папка `app/` публикуется автоматически при push в `main` (`.github/workflows/pages.yml`). В настройках репозитория: Settings → Pages → Source: GitHub Actions.

Открыть сайт в Safari → Поделиться → На экран «Домой». В приложении: значок настроек → ссылка и токен → «Подключить».

## Выписки

- Т-Банк: веб-версия → операции → период → CSV.
- Сбер: приложение → карта → «Выписки и справки» → «Выписка по счёту дебетовой карты» → PDF. Выписка сверяется с итогами в шапке: если строки потерялись, приложение скажет об этом и не внесёт файл.

Периоды могут пересекаться, повторно загруженное пропускается. Выписку кредитки не загружать: покупки задвоятся с погашением.

## Как таблицу правит Claude или человек

Листы можно править как обычно, приложение подхватит изменения при следующем обновлении. Правка и удаление с телефона ищут строку по содержимому: если её за это время поменяли в таблице, приложение покажет ошибку и ничего не тронет. Лист `_импорт` не чистить, иначе старые выписки разберутся заново.

## Обновление приложения

Новая версия подхватывается при втором запуске. Если менялся список файлов в `sw.js`, поднять `VERSION`.
